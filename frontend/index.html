Conectar con Backend Python

Esta interfaz está lista para comunicarse directamente con tu script agentesimple.py.

1. Habilitar CORS en FastAPI

Debes permitir solicitudes cruzadas (CORS) agregando esto en agentesimple.py:

from fastapi.middleware.cors import CORSMiddleware

# ... (debajo de app = FastAPI())
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

2. Conexiones Disponibles en app.js

  • enviarMensajeAlBackend(mensaje) conecta con GET /chat?mensaje_usuario=...
  • enviarAudioAlBackend(blobAudio) conecta con POST /chat/audio
Servir desde FastAPI: Si quieres que el mismo backend sirva el frontend: 
from fastapi.staticfiles import StaticFiles

# Al final de agentesimple.py:
app.mount("/", StaticFiles(directory="frontend", html=True), name="static")
